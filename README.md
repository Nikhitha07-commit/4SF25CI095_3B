# Indian Air Quality Analysis

## About the Project
This project analyzes air quality data from different cities in India using Python and Pandas.

## Dataset
Air Quality Data in India (2015–2020).

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Activities
- Dataset reading and understanding
- Data transformation
- Missing value identification
- Mean imputation
- Insight generation
- Data visualization

## Visualizations
- City-wise average AQI
- Yearly AQI trends
- Monthly AQI analysis
- Pollutant distribution
- Correlation heatmap

## Files Included
- Indian_Air_Quality_Analysis.ipynb
- city_day.csv
- README.md

## Conclusion
The project demonstrates the use of Python data analysis techniques to understand air pollution patterns and generate meaningful insights from real-world data.
